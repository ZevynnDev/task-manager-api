🪐 Sobre

O Task Manager API é um projeto desenvolvido para praticar conceitos de Java e construir uma base para futuros projetos de backend.

A aplicação permite criar, listar, concluir e remover tarefas através de operações básicas de CRUD.

O projeto está sendo desenvolvido de forma incremental, adicionando novas funcionalidades conforme novos conceitos são aprendidos.

💡 Funcionalidades

* ➕ Adicionar novas tarefas
* 📋 Listar tarefas cadastradas
* ✅ Concluir tarefas
* 🗑️ Remover tarefas
* 🔄 Operações básicas de CRUD

⸻

📁 Estrutura do projeto

task-manager-api/
├── Main.java
├── Tarefa.java
├── GerenciadorTarefas.java
└── .gitignore

🧩 Principais classes

Tarefa.java

Representa uma tarefa, armazenando seu nome e seu estado de conclusão.

GerenciadorTarefas.java

Responsável por armazenar e gerenciar as tarefas, realizando as operações de CRUD.

Main.java

Ponto de entrada da aplicação e responsável pelos testes das funcionalidades.

⸻

⭐️ Como executar

1. Clone o repositório

git clone https://github.com/ZevynnDev/task-manager-api.git
cd task-manager-api

2. Compile o projeto

javac *.java

3. Execute

java Main
