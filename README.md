# 🏮 Task Manager API

> Um gerenciador de tarefas desenvolvido em Java, com operações de criação, listagem, conclusão e remoção de tarefas.

### 💫 Sobre

O projeto foi desenvolvido para praticar conceitos de Java e construir uma base para futuros projetos de backend.

Atualmente, o sistema permite gerenciar tarefas através de operações básicas de CRUD. Mais funções serão adicionadas conforme minha progressão com as funcionalidades do backend.

### 🛠️ Tecnologias

* ☕Java

### 💡 Funcionalidades

* Adicionar tarefas
* Listar tarefas
* Concluir tarefas
* Remover tarefas

### ⭐️ Instalação

Siga os passos abaixo para instalar e configurar o projeto.

### 💻 Comandos

```bash
git clone https://github.com/ZevynnDev/task-manager-api.git
cd task-manager-api
javac *.java
java Main
```
